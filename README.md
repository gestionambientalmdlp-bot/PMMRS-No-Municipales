Aplicación web desarrollada con **Google AI Studio** que integra modelos de inteligencia artificial para potenciar la experiencia del usuario.

## 🚀 Características principales
* **Integración con IA:** Utiliza los modelos de Google Gemini a través de Google AI Studio.
* **Interfaz dinámica:** Diseñado para ofrecer respuestas fluidas y en tiempo real.
* **Despliegue ágil:** Optimizado para la nube mediante Vercel.

## 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (o el framework que estés usando, ej. React / Vite).
* **Inteligencia Artificial:** Google AI Studio / Gemini API.
* **Control de versiones:** Git y GitHub.
* **Hosting:** Vercel.
